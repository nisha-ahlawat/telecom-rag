If the data forwarding is performed and the source NG-RAN node receives SDAP SDUs with PDU Set Information Container in the GTP-U extension header on NG-U from the UPF and the target NG-RAN node supports PDU Set based handling, the source NG-RAN node forwards either the PDCP SDUs for DRB-level data forwarding or the SDAP SDUs for PDU-session-level data forwarding with the corresponding PDU Set Information Container in the GTP-U extension header to the target NG-RAN node. For handovers involving Full Configuration, the source NG-RAN node behaviour is unchanged from the description above. In case a DRB DL forwarding tunnel was established, the target NG-RAN node may identify the PDCP SDUs for which delivery was attempted by the source NG-RAN node, by the presence of the PDCP SN in the forwarded GTP-U packet and may discard them.
