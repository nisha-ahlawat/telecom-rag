NG-RAN can also control whether a sidelink logical channel can utilise the resources allocated to a configured sidelink grant Type 1 (see clause 16.9.3.2). For transmissions to RX UE(s) using SL DRX operation, LCP ensures that a TX UE transmits data in the active time of the RX UE(s). For packet filtering, a SL-SCH MAC header including portions of both Source Layer-2 ID and a Destination Layer-2 ID is added to each MAC PDU as specified in clause 8.4. LCID included within a MAC subheader uniquely identifies a logical channel within the scope of the Source Layer-2 ID and Destination Layer-2 ID combination.
