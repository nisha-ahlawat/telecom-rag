Before RACH-less LTM procedure completion, the UE shall not trigger random access procedure if it does not have a valid PUCCH resource for triggered SRs. The following principles apply to LTM: - Security keys are maintained upon an LTM cell switch; - Subsequent LTM is supported. LTM supports both intra-gNB-DU and inter-gNB-DU mobility within the same gNB-CU. LTM supports both intra-frequency and inter-frequency mobility, including mobility to inter-frequency cell that is not a current serving cell. LTM is supported only for licensed spectrum.
