The L2 U2N Remote UE sends the RRCReconfigurationComplete message to the target gNB via the target L2 U2N Relay UE. 11. The data path is switched from indirect path to indirect path between the L2 U2N Remote UE and the target gNB via the target L2 U2N Relay UE. 12. The target gNB sends the UE CONTEXT RELEASE message to inform the source gNB about the success of the path switch. 13. The source gNB sends the RRCReconfiguration message to the source L2 U2N Relay UE to reconfigure the connection between the source L2 U2N Relay UE and the source gNB.
