The BH RLF detection indication, BH RLF recovery indication and BH RLF indication are transmitted as BAP Control PDUs. 9.2.8 Beam failure detection and recovery For beam failure detection, the gNB configures the UE with beam failure detection reference signals (SSB or CSI-RS) and the UE declares beam failure when the number of beam failure instance indications from the physical layer reaches a configured threshold before a configured timer expires. For beam failure detection in multi-TRP operation, the gNB configures the UE with two sets of beam failure detection reference signals, and the UE declares beam failure for a TRP / BFD-RS set when the number of beam failure instance indications associated with the corresponding set of beam failure detection reference signals from the physical layer reaches a configured threshold before a configured timer expires.
