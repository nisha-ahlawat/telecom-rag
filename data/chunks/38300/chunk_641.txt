If the direct path addition/change is failed, the L2 U2N Remote UE always shall trigger RRCReestablishment. 16.21.3.2 Path Failure Report The L2 MP Remote UE in RRC_CONNECTED performs Uu RLM (as described in clause 9.2.7). When the L2 MP Remote UE detects Uu Radio Link Failure (RLF) on the direct path, the L2 MP Remote UE triggers path failure reporting through the indirect path via a RRC message if split SRB1 is configured and the indirect path is not suspended. Otherwise, RRC connection re-establishment is initiated. When the L2 MP Remote UE using PC5 indirect path detects PC5 Radio Link Failure (RLF) and/or Uu link failure on the indirect path, the L2 MP Remote UE triggers path failure reporting through the direct path via a RRC message, if the direct path is not suspended.
