During the Xn-handover preparation procedure, the source gNB sends the stored PDU Set QoS Parameters as part of the QoS profile to the target NG-RAN node. For NG handover, the AMF provides the PDU Set QoS parameters to the target gNB by means of the NGAP HANDOVER REQUEST message.
