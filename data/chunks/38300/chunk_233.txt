The UE applies the TA value measured by itself and performs RACH-less LTM upon receiving the cell switch command, if it does not include any valid TA value. The network may also send a TA value in the LTM cell switch command MAC CE without early TA acquisition. When two TAG IDs are configured for an LTM candidate cell, the gNB-DU to which the LTM candidate cell belongs assigns the same TAG ID pointer value for each TRP to be used by the UEs. Depending on the availability of a valid TA value, the UE performs either a RACH-less LTM or RACH-based LTM cell switch. If the valid TA value is provided in the cell switch command, the UE applies the TA value as instructed by the network.
