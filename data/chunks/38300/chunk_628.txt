Figure 16.21.2.2-1: User plane protocol stack for L2 Multi-path Relay using N3C indirect path Figure 16.21.2.2-2: Control plane protocol stack for L2 Multi-path Relay using N3C indirect path 16.21.3 Control plane procedure for multi-path relaying 16.21.3.1 Path Management The L2 MP Remote UE needs to establish both a direct path and an indirect path. The L2 MP Remote UE adds the indirect path using PC5 link on top of the direct path under the same gNB. And also, the L2 MP Remote UE using PC5 link adds the direct path on top of the indirect path under the same gNB. Meanwhile, the L2 MP Remote UE adds the indirect path using N3C link on top of the only direct path under the same gNB. But it is not allowed that the L2 MP Remote UE using N3C indirect path adds the direct path on top of the indirect path.
