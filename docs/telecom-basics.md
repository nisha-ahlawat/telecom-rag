# Telecom Basics
## 1-  Radio Access Network (RAN)
The Radio Access Network (RAN) is the part of a telecom network that connects user devices, such as smartphones, to the operator's core network using radio signals. It consists of base stations, antennas, and radio equipment that enable wireless communication between users and the network.

### Why it is important

Most network issues such as poor signal quality, call drops, congestion, and low data speeds occur within the RAN. Since this project focuses on Telecom RAN assistance, understanding RAN is essential.

---

## 2. gNB (Next Generation Node B)

A gNB is the 5G base station responsible for providing wireless connectivity to users. It manages radio communication between user devices and the telecom network.

### Functions of a gNB

* Transmits and receives radio signals
* Manages connected users
* Handles mobility and handovers
* Collects network performance information

### Why it is important

Many telecom alarms and performance issues originate from gNBs, making them a critical component in troubleshooting and root cause analysis.

---

## 3. Throughput

Throughput is the amount of data successfully transferred through a network during a specific period of time. It is commonly measured in Mbps (Megabits per second).

### Example

If a user downloads data at 100 Mbps, the network throughput is 100 Mbps.

### Why it is important

A decrease in throughput usually indicates network congestion, resource limitations, or performance issues.

---

## 4. Packet Loss

Packet loss occurs when data packets fail to reach their destination during transmission.

### Causes

* Network congestion
* Poor signal quality
* Hardware failures
* Configuration issues

### Effects

* Video buffering
* Voice call interruptions
* Online gaming lag
* Slow network performance

### Why it is important

Packet loss is one of the key indicators used by telecom engineers to identify network problems.

---

## 5. Latency

Latency is the time taken for data to travel from the source to the destination. It is usually measured in milliseconds (ms).

### Example

If a request takes 20 milliseconds to reach a server and return a response, the latency is 20 ms.

### Why it is important

High latency leads to slow application response times, poor gaming experiences, and delays in communication services.

---

## 6. Alarm

An alarm is a warning generated by a telecom network when an abnormal condition is detected.

### Examples

* Signal Failure
* Congestion Alert
* High CPU Usage
* Radio Link Failure

### Why it is important

Alarms help engineers quickly identify potential issues and are commonly used during troubleshooting and root cause analysis.

---

## 7. Log

A log is a chronological record of events generated by telecom systems and network components.

### Example

10:00 - User connected

10:02 - Signal strength decreased

10:03 - Packet loss increased

10:04 - Alarm triggered

### Why it is important

Logs provide historical information about network behavior and help engineers understand what happened before and during a network issue.
