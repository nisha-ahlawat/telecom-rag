# TS 38.300 Analysis

## Document Overview
TS 38.300 provides an overall description of the 5G NR and NG-RAN architecture. It serves as a high-level specification that explains how different parts of the 5G radio access network interact.

- Physical Layer
- Layer 2 Procedures
- Radio Resource Control (RRC)
- Mobility and State Transitions
- UE Power Saving
- Quality of Service (QoS)
- Security
